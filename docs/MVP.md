# TenderHer MVP

TenderHer turns real procurement opportunities into evidence-backed,
business-specific procurement intelligence.

## MVP Flow

Real Tender
→ Tender Document
→ Requirement Extraction
→ Evidence
→ Business Assessment
→ Bid Readiness Checklist
→ Apify Dataset

## Core MVP

1. Custom Apify Actor
2. One real procurement source
3. Tender discovery
4. Tender information extraction
5. PDF/document extraction
6. AI requirement extraction
7. Evidence references
8. Business profile
9. MATCH / POTENTIAL_GAP / UNKNOWN assessment
10. Bid-readiness checklist
11. Apify Dataset
12. PPE monetization
13. Published Actor
14. Simple demo dashboard
